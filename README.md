# **Compass-New**

## **Usage Instructions**
1. Place the `mlir-opt` and `mlir-translate` files in the `tools` directory.

2. Create a Python environment and install the dependencies:
   ```bash
   conda create -n compass_new python=3.12
   pip install -r requirements.txt
   ```

## **How to Run**
Execute the following command to run the program:
```bash
python main.py
```
